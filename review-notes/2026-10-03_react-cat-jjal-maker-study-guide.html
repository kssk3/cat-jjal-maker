함수형 업데이트:
항상 최신 값으로

함수 안의 counter는 함수가 시작될 때의 값으로 고정(클로저)됩니다. await 뒤에서는 이미 오래된 값일 수 있습니다.

  1. 첫 번째 제출: counter = 3을 기억하고 await
  2. 두 번째 제출: 역시 counter = 3을 기억하고 await
  3. 응답 도착 → 둘 다 3 + 1 = 4로 설정 → 한 번이 사라짐
  4. prev 방식이면 React가 최신 값을 넘겨 3 → 4 → 5
